# M2 — Memory: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The kernel finds RAM in the device tree, manages it with memblock and a buddy page allocator, turns the MMU on with its own page tables, and gets a working heap (`Vec`, `Box`, `Arc`), with spinlocks and an early fault report.

**Architecture:**
- Every algorithm is safe code in `klib`, tested on the Mac: the device-tree walker, memblock, the buddy allocator, the page-table builder, the boot memory layout and slab size classes.
- `foundation` turns physical memory into Rust references, writes the MMU registers, and provides `SpinLock`, `GlobalAlloc` and the exception vectors.
- `kernel`, still `#![forbid(unsafe_code)]`, runs the Linux-shaped boot order and the self-tests.

**Tech Stack:** Rust `stable` (tested with 1.100.0), `core` + `alloc`, `aarch64-unknown-none-softfloat`, QEMU `virt` with `cortex-a72` and 512 MiB, and `dtc` (Homebrew, already installed) for one test fixture.

**Spec:** `docs/study/02-memory.md` (the study note), together with the M2 row and the "After M1" list of the main plan, `docs/superpowers/plans/2026-11-25-rust-kernel.md`.

1. **Layout B** (study note, open question 1):
   - The kernel image stays identity-mapped in `TTBR0`.

   - 4 KiB pages, 48-bit VAs, 4 levels.

5. **New boot order:** parse the DT → console → banner → PSCI → EL check.
   - A missing or broken DTB, or a missing `stdout-path`, now means a **silent halt**. Linux does the same: `setup_machine_fdt` spins with `cpu_relax()` (`arch/arm64/kernel/setup.c:195-196`).
   - The pre-console "loaded at wrong address" message is no longer visible.
6. **Simplifications against Linux, each recorded in the study note:**
   - memblock has a fixed 128 entries and returns `Err(Full)`; it never doubles itself.
   - The spinlock is a ticket lock, not a qspinlock.
   - There is one zone and no per-CPU page lists.
   - Slab classes go up to 1024 bytes; bigger requests take whole pages.
   - Empty slabs are not given back in M2.

## Global Constraints

Every Global Constraint of the main plan still applies. These are the changes and additions for M2:

- **(Proposed change) Where CPU-specific code lives.** It stays under `foundation/src/arch/<arch>/`, **except** pure data formats with no hardware access and no `#[cfg]`. Those may live in `klib/src/arch/<arch>/`. Generic code still never uses `#[cfg(target_arch)]`.
- **(Proposed change) Atomics before the MMU.** The rule becomes "no atomic **read-modify-write** (`swap`, `fetch_*`, `compare_exchange`, and therefore no `SpinLock` and no `Arc`) until the MMU is on".
  - Plain atomic `load` and `store` (Relaxed, Acquire or Release) are allowed. They compile to `ldr`/`str`/`ldar`/`stlr`, which work on Device memory.
  - **The panic and console paths must stay free of read-modify-write and locks**, because the `panic` and `el2` scenarios panic with the MMU off.
- **Memory constants:**
  - `PAGE_SIZE = 4096`;
  - `PAGE_OFFSET = 0xffff_0000_0000_0000`;
  - `MAX_PAGE_ORDER = 10`, so `NR_PAGE_ORDERS = 11` (`include/linux/mmzone.h:31`);
  - the highest physical address we accept is `1 << 48`;
  - `PHYS_OFFSET` = the lowest RAM address, rounded down to 2 MiB.
- **MAIR indices follow Linux** (`arch/arm64/include/asm/memory.h:171-175`): `MT_NORMAL = 0` (`0xff`) and `MT_DEVICE_nGnRE = 4` (`0x04`).
- **Lock order:** the heap lock first, then the page-allocator lock. Never the other way.
- **Log lines copy Linux's text wherever Linux has one:**
  - `psci: probing for conduit method from DT.` (`drivers/firmware/psci/psci.c:291`, with `pr_fmt` "psci: " at `:7`);
  - `Early memory node ranges` and `  node %3d: [mem %#018Lx-%#018Lx]` (`mm/mm_init.c:1818-1820`);
  - `Memory: %luK/%luK available (` (`mm/mm_init.c:2587`);
  - `  ESR = 0x%016lx` (`arch/arm64/mm/fault.c:103`).
- **Every shell runs `. "$HOME/.cargo/env"` first.** In M1, `cargo` was missing from `PATH` without it.
- **Commits.** Each task's commit step adds only the paths it lists. `docs/` is tracked: the user removed the `/docs/` ignore line on 2026-11-25. So study-note and plan updates commit normally.

## Review Focus

1. **A hostile device tree** must give a typed `FdtError`, never a panic or an endless loop. Examples: a property length past the end, an unterminated name, an unknown token, a missing `FDT_END`, nesting deeper than 32, or a `reg` with 3 address cells. → Task 1, the `rejects_*` tests and `reg_with_three_address_cells_is_an_error`.
2. **A device tree without a `/memory` node** must give `MemblockError::NoMemory` and a clear panic, not a kernel with 0 bytes of RAM. → Task 4, `from_device_tree_without_memory_node_is_no_memory`.
3. **memblock `alloc` must never return memory that is reserved or already allocated.** That includes memory at physical address 0, which Linux can't return. → Task 4, `alloc_never_returns_reserved_or_already_allocated_memory` and `alloc_can_return_physical_address_zero`.
4. **The buddy allocator must never merge across a reserved frame or past the end of the frame array.** → Task 5, `never_merges_across_reserved_frames` and `never_merges_past_the_frame_array`.
5. **A bad access after the MMU is on** must print a fault report and power off, not time out. → Task 7, the `unmapped` scenario.

**Interfaces:**
- Consumes: `FdtHeader::parse` and `FdtError` from M1.
- Produces, in `klib::fdt`:
  - `FdtError` gains `BadStructure { offset: usize }`, `UnsupportedCells { address: u32, size: u32 }` and `BadReg`. It still derives `Debug, Clone, Copy, PartialEq, Eq`.
  - `pub struct Fdt<'a>`:
    - `pub fn new(blob: &'a [u8]) -> Result<Fdt<'a>, FdtError>`
    - `pub fn header(&self) -> &FdtHeader`
    - `pub fn root(&self) -> Node<'a>`
    - `pub fn find_node(&self, path: &str) -> Option<Node<'a>>`
    - `pub fn chosen_stdout(&self) -> Option<Node<'a>>`
    - `pub fn memory_nodes(&self) -> impl Iterator<Item = Node<'a>> + 'a`
    - `pub fn mem_reservations(&self) -> impl Iterator<Item = (u64, u64)> + 'a`
  - `#[derive(Clone, Copy)] pub struct Node<'a>`:
    - `pub fn name(&self) -> &'a str`
    - `pub fn property(&self, name: &str) -> Option<&'a [u8]>`
    - `pub fn property_str(&self, name: &str) -> Option<&'a str>`
    - `pub fn is_compatible(&self, c: &str) -> bool`
    - `pub fn children(&self) -> impl Iterator<Item = Node<'a>> + 'a`
    - `pub fn reg(&self) -> Result<impl Iterator<Item = (u64, u64)> + 'a, FdtError>`
  - `#[cfg(test)] pub(crate) struct testing::Builder`:
    - `new()`, `reserve(base: u64, size: u64)`, `begin(name: &str)`, `end()`
    - `prop(name: &str, value: &[u8])`, `prop_u32(name: &str, cells: &[u32])`, `prop_str(name: &str, s: &str)`
    - `raw(word: u32)` writes any token, for the hostile tests
    - `finish() -> Vec<u8>` writes the header, the reservation map, the struct block, `FDT_END` and the strings block. `finish_without_end() -> Vec<u8>` leaves out `FDT_END`.

**Rules:**
- **`Fdt::new` checks the whole structure block once**, like libfdt's `fdt_check_full` (declared at `scripts/dtc/libfdt/libfdt.h:382`). After that, every `Node` method works on bytes that are already known to be good. Even so, use `.get()`, never indexing that can panic.
- **Tokens** (`scripts/dtc/libfdt/fdt.h:53-58`): `BEGIN_NODE = 1`, `END_NODE = 2`, `PROP = 3`, `NOP = 4`, `END = 9`. All are big-endian `u32` at 4-byte-aligned offsets.
- **What the check enforces:**
  - The first non-`NOP` token is `BEGIN_NODE` with an empty name.
  - Names end with a NUL inside the block and are valid UTF-8.
  - A `PROP` has a `len` and a `nameoff` that fit inside the block. Its value fits too. `nameoff` points at a NUL-terminated UTF-8 string inside the strings block.
  - Every `END_NODE` closes an open node, and depth never goes above 32.
  - `END` comes with depth 0, after the root node has closed.
  - Any other token is `BadStructure { offset }`, where `offset` is relative to the struct block.
- **Path lookup.** A path component without `@` matches a node named `name` or `name@…`.
- **`chosen_stdout`:** read `/chosen` `stdout-path` and drop anything from `:` on. If the result doesn't start with `/`, look it up in `/aliases`.
- **`memory_nodes`:** children of the root whose `device_type` is `"memory"` and whose `status` is missing, `"okay"` or `"ok"` (`drivers/of/fdt.c:1050-1054`).
- **`reg`** uses the nearest `#address-cells`/`#size-cells` on the node's parent or further up. If none is found, it uses 1 and 1 (`drivers/of/of_private.h:36,39`).
  - More than 2 cells for either → `UnsupportedCells`.
  - A length that is not a whole number of entries → `BadReg`.
  - A missing `reg` → an empty iterator.

### Task 3: Early exception reporter

**Files:**
- Create: `foundation/src/arch/aarch64/vectors.rs`, `foundation/src/testing.rs`
- Modify: `foundation/src/arch/aarch64/{mod.rs, boot.rs}`, `foundation/src/lib.rs`, `foundation/Cargo.toml` (`[features] test-hooks = []`), `kernel/Cargo.toml` (`test-fault = ["foundation/test-hooks"]`), `vmlinux/Cargo.toml` (`test-fault = ["kernel/test-fault"]`), `kernel/src/init/main.rs`, `xtask/src/scenarios.rs`

**Interfaces:**
- Produces:
  - `#[unsafe(no_mangle)] extern "C" fn early_exception(index: u64, esr: u64, far: u64, elr: u64) -> !`. It prints four lines, then calls `power::power_off()`:

```
rust_kernel: early exception: {name}
  ESR = 0x{esr:016x}
  FAR = 0x{far:016x}
  ELR = 0x{elr:016x}
```

  - `name` comes from `index` 0..16 in Linux's vector order (`arch/arm64/kernel/entry.S:514-529`): `el1t_64_{sync,irq,fiq,error}`, `el1h_64_…`, `el0t_64_…`, `el0t_32_…`.
  - `#[cfg(feature = "test-hooks")] pub fn foundation::testing::breakpoint()`, which runs `brk #0x123`.

  - `pub struct BuddyAllocator<'a>`:
    - `pub fn new(frames: &'a mut [Frame], base: Pfn) -> Self`. It sets every frame to `Reserved`, and `frames[i]` describes `base + i`.
    - `pub fn add_free_range(&mut self, start: Pfn, end: Pfn)` frees in the largest aligned blocks (`mm/memblock.c:2342-2349`) and ignores anything outside the frames.
    - `pub fn alloc(&mut self, order: u8) -> Option<PageBlock>`
    - `pub fn free(&mut self, block: PageBlock)` panics with `"buddy: freeing a block this allocator did not hand out"` if the head frame isn't `Allocated { order }`.
    - `pub fn free_raw(&mut self, pfn: Pfn, order: u8) -> Result<(), BuddyError>` is for `GlobalAlloc`, which can only keep raw addresses (Task 10).
    - `pub fn free_pages(&self) -> u64`, `pub fn free_blocks(&self, order: u8) -> usize`
  - In `memblock.rs`: `pub fn into_page_allocator<'a>(self, frames: &'a mut [Frame], base: Pfn) -> BuddyAllocator<'a>`. It consumes the memblock and frees every free range, rounded inward to whole pages.

**Rules:**
- **The buddy math** is `pfn ^ (1 << order)` (`mm/page_alloc.h:165-180`).
- **Free** (`mm/page_alloc.c:940-1005`): merge while the buddy lies inside the frames and its head frame is `Free { order }` of the same order. The frame that is merged away becomes `Tail`.
- **Allocate** (`__rmqueue_smallest`/`expand`, `mm/page_alloc.c:1714-1924`): take the smallest order that has a free block, split it, and put the upper halves back on the free lists.
- **Frame states.** Every frame except a block's head is `Tail`.

  2. `msr mair_el1, MAIR_EL1_VALUE`

  4. `isb`
  5. `msr ttbr0_el1`, `msr ttbr1_el1`, `isb`
  6. `tlbi vmalle1`, `dsb nsh`, `isb`
  7. Read `SCTLR_EL1`, OR in M (bit 0), C (bit 2) and I (bit 12), write it back. This keeps the RES1 bits.
  8. `isb`, `ic iallu`, `dsb nsh`, `isb` (`assembler.h:739-750`).

### Task 8: `SpinLock` and the recursive-panic guard

**Files:**
- Create: `foundation/src/sync/{mod.rs, spinlock.rs}`, `kernel/src/lib/{mod.rs, locking_selftest.rs}`
- Modify: `foundation/src/lib.rs`, `kernel/src/lib.rs` (declare it as `#[path = "lib/mod.rs"] pub mod lib;`, because a plain `pub mod lib;` gives `E0761`: `src/lib.rs` is the crate root, checked in a scratch crate), `kernel/src/kernel/panic.rs`, `kernel/Cargo.toml` (`test-early-lock = []`, `test-recursive-panic = []`), `vmlinux/Cargo.toml`, `kernel/src/init/main.rs`, `xtask/src/scenarios.rs`

**Interfaces:**
- Consumes: `foundation::mm::mmu_enabled` from Task 7.
- Produces, in `foundation::sync`:
  - `pub struct SpinLock<T>`:
    - `pub const fn new(value: T) -> Self`
    - `pub fn lock(&self) -> SpinLockGuard<'_, T>`
    - `pub fn try_lock(&self) -> Option<SpinLockGuard<'_, T>>`
    - `unsafe impl<T: Send> Sync`, `unsafe impl<T: Send> Send`
  - `SpinLockGuard` implements `Deref`/`DerefMut`, unlocks on `Drop`, and is `!Send`.
- Produces, in kernel: `lib::locking_selftest::locking_selftest()`, which prints `rust_kernel: spinlock self-test OK`.

**Rules:**
- **The ticket lock** follows `include/asm-generic/ticket_spinlock.h:33-69`, but uses two `AtomicU16` fields, `next` and `owner`. Linux uses one `u32` and stores into its low `u16` half, which is a mixed-size atomic access that Rust's memory model doesn't allow.
  - lock: `let t = next.fetch_add(1, Relaxed)`, then spin with `spin_loop()` until `owner.load(Acquire) == t`;
  - unlock: `owner.fetch_add(1, Release)`;
  - try_lock: `let o = owner.load(Acquire)`, then `next.compare_exchange(o, o.wrapping_add(1), Acquire, Relaxed)`.
  - All of them wrap at `u16::MAX`, which the 70,000-cycle self-test crosses.
- **No interrupt masking in M2.** There are no interrupts until M3, which adds `lock_irqsave`.
- **`lock()` and `try_lock()` start with `assert!(mmu_enabled(), "SpinLock used before the MMU is on")`.** The cost is one `mrs`.
- **The panic guard** in `panic.rs` is `static PANICKING: AtomicBool`:
  - `if PANICKING.load(Relaxed) { write "rust_kernel: recursive panic, powering off\n" with console::write_str; power_off() }`;
  - otherwise `PANICKING.store(true, Relaxed)`.
  
  Load-then-store, not `swap`: the handler runs with the MMU off in the `panic` and `el2` scenarios, and there is one CPU until M7, which must change this to `swap`.
- **The self-test** checks four things:
  - `try_lock` returns `None` while the lock is held;
  - dropping the guard releases the lock;
  - a value changed under the lock reads back;
  - 70,000 lock/unlock cycles cross the `u16` ticket wrap, and the counter reads 70,000.

- [ ] **Step 1: Write the failing scenarios.**
  - `boot` gains `"rust_kernel: spinlock self-test OK"` after `"rust_kernel: MMU on"`.
  - New `early-lock`: features `["test-early-lock"]`; the kernel locks a local `SpinLock` before `paging_init`. `must_contain`: `["Kernel panic - not syncing: SpinLock used before the MMU is on"]`. `must_not_contain`: `["MMU on"]`.
  - New `recursive-panic`: features `["test-recursive-panic"]`; after the `dtb` line, the kernel runs `panic!("{}", PanicsWhenShown)`, where `PanicsWhenShown`'s `Display` panics. `must_contain`: `["Kernel panic - not syncing: ", "rust_kernel: recursive panic, powering off"]`.
- [ ] **Step 2: Run and confirm they fail.** Run `cargo xtask test`. Expected: `boot` fails on the self-test line. Without the guard, `recursive-panic` reports `TimedOut`.
- [ ] **Step 3: Implement.**
- [ ] **Step 4: Run and confirm they pass.** Run `cargo xtask test`. Expected: all scenarios are `ok`. **`panic` and `el2` passing is the regression test for "the panic path has no read-modify-write and no lock".**

### Task 10: Heap (`GlobalAlloc`) with slab size classes; README

- Modify: `klib/src/mm/mod.rs`, `foundation/src/mm/mod.rs`, `kernel/src/lib.rs` (`extern crate alloc;`), `kernel/src/mm/{mm_init.rs, selftest.rs}`, `kernel/Cargo.toml` (`test-oom = []`), `vmlinux/Cargo.toml`, `kernel/src/init/main.rs`, `xtask/src/scenarios.rs`, `README.md`

**Interfaces:**
- Consumes: `Pfn` (Task 4); `alloc_pages`, `free_raw` via the locked `PAGES`, and `MmuOn::linear_map` (Tasks 5, 7, 9); `SpinLock` (Task 8).
- Produces, in `klib::mm::slab`:
  - `pub const SIZE_CLASSES: [usize; 10] = [8, 16, 32, 64, 96, 128, 192, 256, 512, 1024];` (the first ten classes at `include/linux/slab.h:804-820`)
  - `pub const HEADER_BYTES: usize = 128;`
  - `pub fn size_class(size: usize, align: usize) -> Option<usize>` gives the index of the smallest class `c` with `c >= max(size, 1)` and `c % align == 0`. `None` means "use whole pages".
  - `pub fn slot_offset(class: usize, slot: usize) -> usize`
  - `pub fn slot_at(class: usize, offset: usize) -> Result<usize, SlabError>`
  - `pub fn objects_per_slab(class: usize) -> usize`
  - `#[derive(Debug, PartialEq, Eq)] pub enum SlabError { DoubleFree, NotAnObject, NotASlab }`
  - `pub struct SlabHeader` (magic, class, in-use count, `on_partial`, `next: Option<Pfn>`, `free: [u64; 8]`; `size_of <= HEADER_BYTES`, asserted with `const`), with:
    - `pub fn new(class: usize) -> Self`
    - `pub fn alloc_slot(&mut self) -> Option<usize>`
    - `pub fn free_slot(&mut self, slot: usize) -> Result<(), SlabError>`
    - `pub fn is_full(&self) -> bool`, `pub fn is_slab(&self) -> bool` (magic), `pub fn class(&self) -> usize`
  - `pub trait SlabPages { fn new_slab_page(&mut self) -> Option<Pfn>; fn header(&mut self, pfn: Pfn) -> &mut SlabHeader; }`
  - `pub struct Slabs`:
    - `pub const fn new() -> Self`
    - `pub fn alloc(&mut self, pages: &mut impl SlabPages, class: usize) -> Option<(Pfn, usize)>`
    - `pub fn free(&mut self, pages: &mut impl SlabPages, pfn: Pfn, slot: usize) -> Result<(), SlabError>`
- Produces, in `foundation::mm`:
  - `pub fn init_heap(mmu: &MmuOn)`, which panics if no page allocator is installed;
  - `heap::KernelHeap`, which is the `#[global_allocator]`.

**Rules:**
- **Slab layout.** A slab is one page. The header sits in its first `HEADER_BYTES`, and objects start at `round_up(128, the largest power of two that divides the class size)`. **The header is never handed out**, and `klib` only ever gets `&mut SlabHeader`, never the whole page. So safe code never holds a reference to memory a caller owns.
- **`Slabs`** keeps one singly linked list of partial slabs per class:
  - `alloc` takes the head of the list and unlinks the slab when it becomes full;
  - `free` pushes a slab that was full back onto the list;
  - empty slabs stay (Decision 6).
- **`KernelHeap`:**
  - It returns null while `static READY: AtomicBool` is false. That happens before `init_heap`, possibly with the MMU off, and it takes no lock.
  - A request with `size_class == None` takes `alloc_pages(order)`, where `order` is the smallest with `4096 << order >= max(size, align)`. Buddy blocks are naturally aligned.
  - `dealloc` finds the pfn through `linear_map().virt_to_phys`. Small requests go to `Slabs::free`; big ones go to `free_raw(pfn, order)`, recomputing `order` from the layout.
  - An `Err` from either is `panic!("kfree: {:?} at {:#x}", e, ptr)`.
  - Lock order: `SLABS` first, then `PAGES`.
- **Rust's built-in out-of-memory handler** panics with `memory allocation of N bytes failed`.
- **The heap self-test** prints `rust_kernel: heap self-test OK`. It checks:
  - a `Vec<u32>` of 10,000 pushes sums to `49_995_000`;
  - a `Box<[u8; 100]>`;
  - `Arc` `strong_count` is 2 after a clone;
  - `format!` gives a `String`;
  - a `Vec<u8>` with a capacity of 100,000 (the page path);
  - a `Box` of `#[repr(align(4096))] struct Aligned([u8; 16])` has an address that is a multiple of 4096 (taken with `&*b as *const _ as usize`, which is safe code).
